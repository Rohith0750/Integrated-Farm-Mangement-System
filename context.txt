1. EXECUTIVE SUMMARY & PROJECT GOAL
--------------------------------------------------------------------------------
PRJ_533 is an integrated agricultural resource management and decision-support 
platform engineered to centralize farm operations, optimize resource utilization 
(water, fertilizer, equipment, capital), and provide data-driven predictive 
insights for modern farming.

The platform bridges raw agricultural datasets, open environmental/weather APIs, 
and machine learning models (crop suitability recommendation, yield forecasting, 
and leaf disease diagnosis via computer vision) with an intuitive control panel 
for farmers, farm managers, and agricultural advisors.

4. SYSTEM ARCHITECTURE & TECHNICAL SPECIFICATIONS
--------------------------------------------------------------------------------
Architectural Pattern: Decoupled Multi-Tier System

• Tier 1: Client Application (Frontend)
  - Tech: React.js, TypeScript, Vite/Next.js, Tailwind CSS, Lucide Icons, Recharts, Leaflet.js
  - Role: Responsive UI dashboard for farm analytics, disease diagnosis, field maps, and finance.

• Tier 2: Core Backend API (Server)
  - Tech: Node.js, Express.js, MongoDB (Mongoose ORM), JWT Authentication, Winston Logger
  - Role: Business logic, user auth, field management, resource scheduling, external weather API consumption, data proxying to ML service.

• Tier 3: AI/ML Microservice (Intelligence)
  - Tech: Python 3.10+, FastAPI, Uvicorn, Scikit-Learn, PyTorch / OpenCV, XGBoost, Pandas, NumPy
  - Role: Serves endpoints for ML predictions (Crop recommendation based on NPK/pH/rainfall, yield prediction, plant disease leaf image classification).

• Tier 4: Database Storage
  - Tech: MongoDB (Atlas / Self-hosted container)
  - Role: Persists Users, Farms, Fields, Soil Logs, Crop Cycles, Disease Logs, Equipment, Labor, Financial Ledger.
